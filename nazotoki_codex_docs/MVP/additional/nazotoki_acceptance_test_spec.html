1. 目的

本資料は、MVP実装が完成したかどうかを判断するための受け入れテスト仕様書である。Codexによる実装後、本資料のテストを満たすことを完成条件とする。

2. 参加者側テスト

IDテスト内容期待結果重要度
P-01存在するルーム番号と名前を入力して参加する。待機画面または問題画面に遷移する。高
P-02存在しないルーム番号で参加する。エラーメッセージが表示される。高
P-03名前未入力で参加する。入力必須エラーが表示される。高
P-04問題開始前に参加する。待機中であることが表示される。中
P-05問題開始後に参加する。現在の問題画像が表示される。高
P-06正答を入力して送信する。正解表示になり、得点が加算される。高
P-07誤答を入力して送信する。不正解表示になり、得点は加算されない。高
P-08空欄で送信する。空欄エラーが表示され、送信されない。中
P-09正解済みの問題に再度正答を送る。得点は二重加算されない。高
P-10締切後に解答を送る。受付終了メッセージが表示され、得点は加算されない。高

3. 出題者側テスト

IDテスト内容期待結果重要度
A-01出題者アカウントでログインする。管理画面に遷移する。高
A-02未ログインで管理画面URLへアクセスする。ログイン画面へリダイレクトされる。高
A-03ルームを作成する。ルーム番号が発行される。高
A-04問題画像、正答、配点を登録する。問題一覧に追加される。高
A-05問題を開始する。参加者側に問題が表示される。高
A-06解答を締め切る。参加者側で解答できなくなる。高
A-07得点一覧を表示する。参加者ごとの得点が表示される。高
A-08次の問題を開始する。参加者側の表示問題が切り替わる。中

4. APIテスト

ID対象確認内容期待結果
API-01join-room有効なルーム番号で参加する。participant_idが返る。
API-02join-room無効なルーム番号で参加する。404または業務エラーを返す。
API-03current-question現在問題を取得する。画像URL、問題タイトル、状態のみ返る。
API-04current-question正答文字列が含まれていないか確認する。正答は返らない。
API-05submit-answer正答を送信する。correct=true、獲得点が返る。
API-06submit-answer誤答を送信する。correct=false、獲得点0が返る。
API-07submit-answer同一問題へ正答を再送する。得点は増えない。
API-08admin系API未認証で操作する。401または403を返す。

5. セキュリティテスト

以下の項目は必ず確認する。通過しない場合、本番利用不可とする。
  • ブラウザの開発者ツールで正答文字列が確認できない。
  • ネットワークレスポンスに正答文字列が含まれていない。
  • service role keyがクライアントJSに含まれていない。
  • 参加者がAPIへ任意のscoreを送っても得点を改ざんできない。
  • 未認証ユーザーが問題開始・締切APIを実行できない。
  • 他ルームの問題・参加者情報を参照できない。

6. 本番前確認

項目確認内容
スマホ表示360px幅程度でも問題画像・解答欄・送信ボタンが使える。
通信エラーネットワーク切断時に分かりやすいエラーが出る。
画像サイズ問題画像が重すぎず、表示に時間がかかりすぎない。
本番URL参加者URLと出題者URLが正しくアクセスできる。
バックアップ本番前に問題データを確認・控えとして保存する。
