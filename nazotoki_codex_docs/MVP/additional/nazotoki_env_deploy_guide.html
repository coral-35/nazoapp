1. 目的

本資料は、謎解き企画用アプリをローカルで実行し、外部公開するための環境構築・デプロイ手順をまとめる。実装者が変わっても同じ手順で再現できる状態を目指す。

2. ローカル環境構築

2.1 必要ツール

  • Node.js
  • npm または pnpm
  • Git
  • VS Codeなどのエディタ
  • Supabaseアカウント
  • Vercelアカウント

2.2 初期セットアップ例

git clone [repository-url]
cd nazotoki-app
npm install
cp .env.example .env.local
npm run dev

2.3 .env.example例

NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
NEXT_PUBLIC_APP_URL=http://localhost:3000

3. Supabase準備

  1. Supabaseで新規プロジェクトを作成する。
  2. Project URLとanon keyを取得する。
  3. service role keyを取得し、サーバー側環境変数として設定する。
  4. SQL Editorでschema.sqlを実行する。
  5. Storageで問題画像用バケットを作成する。
  6. 出題者ログイン用のユーザーを作成する。
service role keyは強い権限を持つため、Gitにコミットしてはいけない。

4. Vercelデプロイ

  1. GitHubにリポジトリを作成する。
  2. VercelでGitHubリポジトリをインポートする。
  3. Framework PresetがNext.jsになっていることを確認する。
  4. Environment Variablesを設定する。
  5. Deployを実行する。
  6. 発行されたURLへアクセスして動作確認する。

4.1 Vercelに設定する環境変数

変数名ProductionPreviewDevelopment
NEXT_PUBLIC_SUPABASE_URL設定設定任意
NEXT_PUBLIC_SUPABASE_ANON_KEY設定設定任意
SUPABASE_SERVICE_ROLE_KEY設定設定任意
NEXT_PUBLIC_APP_URL本番URLPreview URL任意

5. 実行手順

5.1 ローカル実行

npm run dev

ブラウザで http://localhost:3000 にアクセスする。

5.2 ビルド確認

npm run build
npm run start

ローカル開発では動いても、本番ビルドで失敗することがあるため、デプロイ前に必ず確認する。

5.3 テスト実行

npm run lint
npm run test

テスト環境を整備した場合は、受け入れテスト前に自動テストを実行する。

6. デプロイ後チェック

項目確認内容
トップページ本番URLで表示できる。
参加者画面スマホからルーム参加できる。
出題者ログイン本番環境でログインできる。
画像表示Storageの画像が表示される。
解答判定正答・誤答が正しく処理される。
秘密情報service role keyが公開されていない。
