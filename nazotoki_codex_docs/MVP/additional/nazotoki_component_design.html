1. 目的

本資料は、Next.js/Reactで画面を実装する際のページ構成とコンポーネント分割を定義する。Codexに実装させる際、画面ごとの責務が混ざらないようにすることを目的とする。

2. 画面一覧

パス案画面利用者役割
/トップ画面参加者/出題者参加者画面・出題者画面への導線を表示する。
/joinルーム参加画面参加者ルーム番号と名前を入力する。
/play/[roomCode]問題解答画面参加者問題表示、解答入力、得点表示を行う。
/admin/login出題者ログイン画面出題者認証を行う。
/admin/roomsルーム一覧画面出題者ルーム作成・選択を行う。
/admin/rooms/[roomId]ルーム管理画面出題者問題管理、進行操作、得点確認を行う。

4. 状態管理

状態保持場所理由
参加者IDlocalStorage + DBページ更新後の復帰に使う。ただし得点計算には使わない。
現在問題DB出題者操作と参加者表示を同期するため。
得点DB改ざん防止と整合性確保のため。
正答DBのみ参加者側へ漏らさないため。
UI入力値React state画面入力中のみ必要なため。
localStorageは復帰補助には使えるが、得点や正誤判定の根拠にしてはいけない。

5. UI/UX方針

  • 参加者側はスマートフォン優先で設計する。
  • 解答欄と送信ボタンは問題画像の直下に配置する。
  • Enterキーで送信できるようにする。
  • 送信中はボタンをdisabledにし、連打を抑制する。
  • 正解・不正解は色とテキストの両方で示す。
  • 出題者側の危険操作には確認ダイアログを表示する。
  • 問題開始、締切、企画終了ボタンは近接配置しすぎない。
